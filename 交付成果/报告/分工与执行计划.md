## 一、项目信息（已拍板，不再改）

| 项 | 内容 |
|---|---|
| 题目 | 基于无人机高光谱影像的校园地物分类——以珠海校区为例 |
| 截止 | 2026-11-25（报告 Word 20页+、PPT、课堂展示+答辩） |
| 数据 | 只用 1 条条带：`raw_10096`（756×1246×272波段，约1GB，400–1000nm，已是反射率） |
| 类别 | 草地、树木、塑胶跑道、道路/停车场、建筑屋顶、阴影（6类；先跑5类也行） |
| 方法 | PCA 降维 → 支持向量机(SVM) vs 随机森林(RF) 对比 |
| 验证 | 混淆矩阵 / 总体精度OA / Kappa + 地面实测光谱做光谱角(SAM)交叉验证 |
| 工具 | Python（numpy/sklearn/matplotlib）+ labelme 标注；**不用 ENVI** |
| 加分项 | 时间够的话：荔枝岛"荔枝树 vs 普通树"细分成第7类 |

## 二、成员分工（填真名和联系方式）

> 原则：**只有 A 碰大数据**；B/C 只碰"不需要大数据"的活 + 一个 11MB 小文件。

## 三、协作与数据共享规则（重要）

1. **大数据不传**：10GB 原始数据只在 A 电脑。其他人不下载、不合并。
2. **实测光谱.zip（11MB）**：A 直接发群里，C 拿去整理。
3. **中间产物共享**（都很小，做完即发群）：
   - A 导出条带的**假彩色 PNG** → B、C 用它标样本/认地物；
   - A 出**分类结果图、精度表** → 全组写报告用；
   - C 出**光谱曲线图、SAM 结果** → 全组写报告用。
4. **B/C 想跑代码**：只需装 Python + 让 A 发那 1 条条带（约1GB）到网盘，各自跑同一份脚本；不想跑也不影响分工。
5. **共享文档**：用腾讯文档/飞书开一个《报告大纲》，三人并行往里填，每章标注"谁负责"。
