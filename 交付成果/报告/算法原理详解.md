# RF / MLP / SVM 算法原理与具体处理过程详解

> 用途：让你**看懂并能给老师讲清**三个模型在我们项目里到底做了什么、为什么这样做、结果为何如此。
> 对应数据：raw_7216 训练条带，5 类（水体/阴影、草地、树木、建筑、道路）。

---

## 0. 总览：三个模型用同一套数据、同一条预处理流水线

- 输入 `X`：每一行是**一个像素**的 225 个波段（450–950nm）反射率，形如 `(10000, 225)`。
- 标签 `y`：每个像素属于哪一类，取值 0–4（水体/阴影=0、草地=1、树木=2、建筑=3、道路=4）。
- 数据量：7216 条带共 518,385 个标注像素，**样本均衡后 10,000 个**（每类最多取 2000）。
- 划分：**70% 训练 / 30% 测试**（`stratify` 保证每类在训练、测试里的比例一致）。

结论先行（7216 随机划分精度）：

| 模型 | OA | Kappa |
|---|---|---|
| **随机森林 RF** | **80.6%** | 0.758 |
| 多层感知机 MLP | 79.1% | 0.739 |
| 支持向量机 SVM | 76.4% | 0.705 |

---

## 1. 三模型共用的预处理（必须先懂这 4 步）

### 1.1 波段选择：272 → 225
传感器有 272 个波段（400–1000nm），但**两端（400–450nm、950–1000nm）信噪比低、噪声大**，我们只保留 450–950nm 的 225 个波段。
> 为什么：高光谱首尾波段的反射率不可靠，去掉能减少噪声干扰。

### 1.2 样本均衡：每类最多 2000
原始标注里有的类像素极多（如大片水体/建筑）、有的很少，直接训练会让模型"偏向"大类。
> 做法：每类随机抽最多 2000 个像素，共 5×2000=10000。让 5 类"平权"。

### 1.3 标准化（StandardScaler，Z-score）
对每个波段：`(x − 该波段均值) / 该波段标准差`。
> 为什么：不同波段的反射率数值范围差异大，标准化后各波段量纲一致，模型不会被"数值大的波段"带偏。MLP 尤其需要。

### 1.4 PCA 降维：225 → 3~4 维
高光谱 225 个波段**高度相关**（相邻波段几乎一样），存在大量冗余。PCA 找到方差最大的几个"主成分"方向，保留 99% 方差时**只需要 3~4 个主成分**就够了。
> 作用：去冗余、降噪、加速、降低过拟合风险。三个模型都输入 PCA 后的 3~4 维特征。

> **一句话给老师讲**：我们把 225 个波段先标准化、再 PCA 压到 3~4 个主成分，去掉相邻波段的冗余，再喂给分类器。

---

## 2. 精度指标（三个模型都用）

- **OA（总体精度）**：测试集里分类正确的像素占比 = 正确数 / 总数。最直观。
- **Kappa**：扣掉"瞎猜也能蒙对"的部分后的精度，比 OA 更严格（范围 −1~1，越大越好）。
- **混淆矩阵**：行=真实类，列=预测类；对角线是分对的，非对角线是分错的。能看出"谁和谁混"。

## 3. SVM（支持向量机）—— 结果 76.4%

### 3.1 一句话直觉
在特征空间里找一条（或一个）**离两类都尽可能远的分界面**，也就是"最大间隔"的超平面。

### 3.2 原理三步
1. **超平面**：把空间一分为二的线/面，例如 `w·x + b = 0`。
2. **间隔（margin）**：分界面到最近样本的距离。SVM 的目标是**让这个间隔最大**——间隔越大，对新样本越"稳"。
3. **支持向量**：恰好落在间隔边界上的那几个样本点。**只有它们决定分界面**，其他样本根本不起作用（这是 SVM 名字的由来）。

### 3.3 线性分不开怎么办？→ 核技巧（我们用 RBF 核）
很多真实数据线性分不开。RBF（高斯）核相当于把样本**映射到更高维**，在高维里再找线性分界面。
RBF 核函数：`K(x, x') = exp(−γ·‖x − x'‖²)`，衡量两个样本的"相似度"。

### 3.4 两个关键参数
- **C**（我们取 10）：惩罚"分错"的力度。C 越大越不容忍错分、越可能过拟合；C 越小边界越宽松。
- **gamma**（我们取 `scale`）：单个样本的影响范围。gamma 大→每个样本影响大→容易过拟合。
  `gamma='scale'` = 自动按特征数设置（`1/(n_features × 方差)`），省得手动调。

### 3.5 多分类怎么做
我们 5 类。sklearn 用"一对一"（one-vs-one）：每两类训练一个 SVM（共 C(5,2)=10 个小分类器），投票决定最终类。

### 3.6 我们到底用了什么
```python
SVC(kernel='rbf', C=10, gamma='scale', random_state=0)
# 输入：PCA 后的 3~4 维特征（已标准化）
```

### 3.7 为什么 SVM 结果偏弱（76.4%）
SVM 对**参数 C、gamma 很敏感**，且主要靠"边界样本"决定分界面；在高光谱这种"多类、类间有重叠"的场景里，非线性边界不好调，容易被草-树、楼-路这种光谱重叠区拖累。

### 3.8 怎么给老师讲
> "SVM 就是找最大间隔超平面；线性分不开就用 RBF 核映射到高维。我用 C=10、gamma=scale，多分类用一对一投票，最终 OA 76.4%。它比 RF 低，因为对参数敏感、在类间光谱重叠时不够稳。"

## 4. RF（随机森林）—— 结果 80.6%（最高）

### 4.1 一句话直觉
**种很多棵决策树，让它们投票**。每棵树只看一部分样本、一部分波段，各自做判断，最后多数表决——所以又稳又不容易过拟合。

### 4.2 决策树是什么（RF 的"零件"）
一棵树 = 一连串"如果…就…"的切分：
- 从根节点开始，选**一个波段 + 一个阈值**把数据切成两份（比如"近红外波段 > 0.3 的往左"）；
- 每个子节点继续切，直到叶子节点里基本只剩一类（或用完深度）；
- 判断规则就是"从根走到叶子"。

### 4.3 为什么叫"随机"森林（关键，两处随机）
1. **样本随机（bootstrap）**：每棵树从训练集里**有放回地随机抽**一份样本（有的样本被抽多次、有的没抽到），所以每棵树看到的训练数据不一样。
2. **特征随机**：每个节点只从**随机选出的少数几个波段**里挑最优切分，而不是看全部 225 个波段。

> 好处：两处随机让每棵树"各有所长、各不相同"，树与树之间的错误互相抵消，整体方差下降，**抗过拟合**。这正是 RF 在高光谱分类上常年表现好的原因。

### 4.4 投票
300 棵树各自预测一个类，取**多数票**作为最终结果。

### 4.5 特征重要性（我们画成波长曲线的那个）
一个波段**在多少棵树、多大程度上被用来切分**，累加归一化就是"特征重要性"。值越大，说明它对区分地物越关键。我们据此画出了 `RF波段重要性_raw_7216.png`。

### 4.6 我们到底用了什么
```python
RandomForestClassifier(n_estimators=300, random_state=0, n_jobs=-1)
# 输入：PCA 后的 3~4 维特征
```

### 4.7 怎么给老师讲
> "随机森林是 300 棵决策树投票。每棵树用 bootstrap 随机抽样本、每个节点随机抽波段，所以树之间差异大、互相纠错，抗过拟合。它对高光谱这种波段多、有噪声的数据特别稳，所以拿到 80.6%，三个模型里最高。"

## 5. MLP（多层感知机 / 简单神经网络）—— 结果 79.1%

### 5.1 一句话直觉
一堆"神经元"分好几层连起来，**自动学特征**：前面几层把输入逐步变换、组合，最后一层输出每个类的概率。

### 5.2 我们的结构
```
输入(3~4 维) → 全连接层 128 个神经元(ReLU) → 全连接层 64 个神经元(ReLU) → 输出 5 个(softmax)
```

- **全连接层**：每个神经元 = 上一层所有神经元的加权和 + 偏置。
- **ReLU 激活**：`f(z)=max(0,z)`，引入非线性，否则多层等价于一层线性。
- **softmax 输出**：把 5 个输出变成 5 个概率（和为 1），取概率最大的作为类别。

### 5.3 怎么训练：反向传播 + 梯度下降
1. 前向算一遍，得到预测概率；
2. 用**交叉熵损失**衡量"预测和真实差多少"；
3. **反向传播**把误差从输出层往回传，逐层算出梯度；
4. **Adam 优化器**沿梯度方向更新每个权重，让损失越来越小。

### 5.4 怎么防过拟合
- **early stopping**：训练时留一小块验证集，一旦验证集表现不再变好就提前停，防止死记训练集。

### 5.5 我们到底用了什么
```python
MLPClassifier(hidden_layer_sizes=(128, 64), max_iter=300,
              early_stopping=True, random_state=0)
# 输入：PCA 后的 3~4 维特征
```

### 5.6 为什么 MLP 居中（79.1%）
MLP 比 SVM 灵活（自动学非线性特征），所以更高；但**数据量（1万）相对网络而言不算大**，且我们做 PCA 后特征只有 3~4 维，MLP 的优势没完全发挥，所以略低于 RF。

### 5.7 怎么给老师讲
> "MLP 是两层全连接加 ReLU、输出 softmax 的简单神经网络，用交叉熵损失 + Adam 反向传播训练，early stopping 防过拟合。它比 SVM 强（自动学特征），但样本有限、特征已 PCA 降维，所以比 RF 略低，OA 79.1%。"

## 6. 三模型对比与结论（答辩直接可用）

| 模型 | 核心思想 | 优点 | 缺点 | OA |
|---|---|---|---|---|
| SVM | 最大间隔超平面 + RBF 核 | 理论优雅、小样本也好用 | 对参数敏感、多类重叠时弱 | 76.4% |
| RF | 多决策树集成投票 | 抗噪、抗过拟合、高维鲁棒 | 可解释性一般（但可看特征重要性） | **80.6%** |
| MLP | 多层非线性映射 | 自动学特征、灵活 | 需要调参、样本少时易过拟合 | 79.1% |

**结论**：在本任务（高光谱逐像素 5 分类、225 波段）上，**随机森林最优**。原因是高光谱波段高度冗余、类间有光谱重叠，RF 的"集成 + 随机"机制对这类噪声和冗余最鲁棒；SVM 受参数敏感拖累；MLP 因样本量有限未能充分发挥。

---

## 7. 答辩高频问题（提前背熟）

1. **"为什么要 PCA 降维？"** → 225 个波段高度相关、冗余大，PCA 去冗余降噪，99% 方差只需 3~4 维。
2. **"SVM 的 C 和 gamma 是什么？"** → C 惩罚错分的力度，gamma 控制单个样本影响范围。
3. **"随机森林为什么能抗过拟合？"** → 两处随机（bootstrap 抽样本 + 随机抽特征）让树各不相同、错误互相抵消。
4. **"MLP 为什么不如 RF？"** → 样本 1 万、特征已降到 3~4 维，MLP 优势没发挥；RF 对高维冗余更鲁棒。
5. **"OA 和 Kappa 区别？"** → OA 是正确率；Kappa 扣掉随机蒙对的成分，更严格。
6. **"混淆矩阵怎么看？"** → 行=真实、列=预测，对角线分对，非对角线看谁和谁混。
