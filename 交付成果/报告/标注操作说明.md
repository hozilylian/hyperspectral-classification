# 高光谱标注操作说明（零基础版）

> 你要做的事一句话：用 labelme 在一张图上，把 5 类地物**圈多边形**标出来，最后把一个 `.json` 文件发回组长。

---

## 一、准备工作
- 一台 Windows 电脑；
- 组长发你的图片文件（例如 `raw_10096_truecolor.png`）；
- ⚠️ **务必直接用组长发的原图文件**，不要用手机截图、裁剪、缩放，否则坐标会对不上。

## 二、装 Python（电脑里没有才装）
1. 按 `Win + R`，输入 `cmd`，回车，打开黑窗口（命令提示符）；
2. 输入 `python --version` 回车：
   - 显示 `Python 3.x.x` → 已装，跳到第三步；
   - 报错/没有 → 去 https://www.python.org/downloads/ 下载 Python 3.12，安装时**一定勾选 “Add Python to PATH”**，其余一路下一步。

## 三、安装 labelme（黑窗口里复制粘贴一条命令）
```
pip install labelme
```
下载慢就用清华镜像：
```
pip install labelme -i https://pypi.tuna.tsinghua.edu.cn/simple
```
看到 `Successfully installed ...` 就成功。

## 四、启动 labelme
黑窗口里输入：
```
labelme
```
回车，会弹出一个图形界面。

## 五、打开图片
1. 点左上角 **Open**；
2. 找到组长发的图片（如 `raw_10096_truecolor.png`）打开。

## 六、画多边形
1. 点左侧工具栏的 **Create Polygons**（创建多边形）；
2. 在图上**沿一个地物的边缘一圈一圈点鼠标左键**（沿一片草地 / 一棵树 / 一栋楼 / 一条路 / 一块水面/阴影的外轮廓点）；
3. 点完一圈后按 **回车键（Enter）** 闭合；
4. 弹出框让你填标签 → 填下面 5 个词之一 → 点 OK；
5. 换下一个地物，重复 2–4。

### 标签名（一字不差，直接复制）
```
水体/阴影
草地
树木
建筑
道路
```
> 注意：第一个「水体/阴影」中间是**英文斜杠 /**，别打成中文斜杠或顿号。

## 七、保存
全部标完后，点左上角 **Save**（或按 `Ctrl + S`）。
会在图片旁边生成一个**同名 .json 文件**（如 `raw_10096_truecolor.json`）。

## 八、交回
把那个 `.json` 文件发回组长即可（**只发 json，不用发图片**）。

---

## 九、标注质量要求（重要）
1. **每类多标几处**：比如"草地"别只标一块，操场边、楼边的草地各标几块；
2. **沿纯净区域标**：别贴地物边缘，往里缩一点（边缘是"混合像元"，会带偏模型）；
3. **拿不准的地物跳过**：看不清就不标，宁缺毋滥；
4. 尽量 **5 类都标到**，每类多标几块。

## 十、常见问题
- **`pip` 不是内部或外部命令**：装 Python 时没勾 “Add to PATH”，重装勾上。
- **labelme 打不开**：确认黑窗口里输入的是全小写 `labelme`。
- **点 Open 找不到图**：先把图片存到桌面，再从桌面打开。
- **标签填错了想改**：左侧选 **Edit Polygons** 后点那个多边形，或在右侧"Polygon Labels"列表里点它改标签。
- **json 在哪**：默认和图片在同一个文件夹里。
