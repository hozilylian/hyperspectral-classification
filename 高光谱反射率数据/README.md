# 高光谱地物分类 —— 数据文件夹说明

> 本文件夹是"高光谱反射率数据"的工作目录。所有脚本**在本目录下运行**（`python xxx.py`）。

## 目录结构

| 文件夹 | 放什么 |
|---|---|
| `原始数据/` | ENVI 原始数据：`raw_*.hdr`(头) + `raw_*`(272波段二进制) + `raw_*_rd_rf_or2.tif`(GeoTIFF) |
| `标注/` | 假彩色 PNG（供 labelme 标注）+ 标注生成的 `.json` |
| `训练集/` | 转换好的训练集：`X_*.npy`(光谱) / `y_*.npy`(标签) / `coords_*.npy`(坐标) / `class_map_*.txt` |
| `结果/` | 分类结果图、各类平均光谱图 |
| `旧文件/` | 早期生成、已被新版取代的文件（确认无误后可删） |

## 三步流程

```powershell
# ① 导出假彩色 PNG（已导过可跳过；换条带再导）
python export_all_rgb.py

# ② 用 labelme 在 标注/*.png 上画多边形 -> json 存回 标注/
#    然后把 json 转成训练集：
python labelme_to_dataset.py            # 默认 raw_10096
python labelme_to_dataset.py raw_5232   # 处理另一条条带

# ③ 训练 + 精度(随机/空间) + 出图
python train_classify.py                # 默认 raw_10096
python train_classify.py raw_5232
```

## 类别（labelme 标签文字必须一字不差）

`建筑屋顶` `道路` `湖泊` `斑马线` `车` `大树`

## 数据流转（PNG 只用于标注，不参与训练）

1. **原始数据**：每个像素是 272 个波段的一条光谱曲线（400–1000nm），完整信息在 `原始数据/` 里；
2. **假彩色 PNG**：只挑 3 个波段（近红外/红/绿）拼成图，**仅供人眼看清位置、画多边形**；
3. **标注 json**：只记录"哪些像素属于哪类"的**坐标**，不含光谱；
4. **训练集**：脚本回到 `原始数据/` 的 272 波段文件，按坐标取出每个像素的**完整光谱**喂给模型。

所以：PNG 转成 3 通道确实丢了大量信息，但那只是"给人看的预览图"；**训练用的是原始 272 波段，分析环节零信息损失**。
